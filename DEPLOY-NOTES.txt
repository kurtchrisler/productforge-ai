ProductGenie AI — Sales Kit + Kindle EPUB, extended to all product kinds
==========================================================================

What this does
---------------
Previously, "Download Sales Kit" (sales page + download page) and
"Download for Kindle (.epub)" only ever showed up for document-kind
products (ebooks, guides, planners, workbooks, templates, checklists).
Crossword/word search puzzle books and coloring books never got either
button — not a bug, just not built yet.

This update extends both features to cover every product kind:

- Kindle .epub for crossword/word search books: the puzzle grid and
  clues are rendered as plain HTML tables (unsolved puzzles first, then
  an "Answer Keys" section with the solved grids) — real reflowable
  text, not a screenshot, so it stays a small file and displays properly
  on any Kindle device or app.
- Kindle .epub for coloring books: repackages the same AI-generated
  line-art PNGs already used in the PDF as one full-page image per
  chapter — like a picture-book or comic EPUB.
- Sales Kit for puzzle and coloring books: the AI sales-copy generator
  now works from each kind's own real content (puzzle themes/difficulty,
  or page captions) instead of requiring prose chapters. Same rule as
  before — nothing about price, checkout, or guarantees is invented;
  those stay as visible bracketed placeholders for you to fill in.

No new AI calls were added anywhere in the generation pipeline — the EPUB
changes are pure repackaging of content that was already being generated,
and the Sales Kit change only touches which content it's allowed to run on.

    git push

3. Deploy on the server
---------------------------
    ssh cloudb23@144.208.68.97
    cd ~/productforge-ai
    git pull && ./deploy.sh

Nothing needs deleting this time — every file in this update is a
replacement of an existing file, nothing was removed.

4. Existing products
------------------------
This only affects NEW downloads going forward. Existing puzzle and
coloring-book products won't have an .epub file yet (their epub_path is
still empty in the database), so the Kindle download button won't appear
for them until you click "Regenerate cover" on that product — that
re-runs the same code path and builds the missing .epub alongside a
refreshed cover, at no extra AI cost. There's no cover-only refresh that
skips the EPUB build, and no separate "generate epub" action — the
regenerate-cover button is the retry path for both.
