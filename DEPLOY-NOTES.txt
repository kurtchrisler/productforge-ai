ProductGenie AI — fix: scripts/ missing from the deployed container
========================================================================

What happened
---------------
Docker's build is two stages: a "builder" stage that has your full source
(including scripts/) and runs npm run build, and a separate, smaller
"runner" stage that actually ships -- it only copies over the specific
things the running app needs (package.json, node_modules, the compiled
.next output, public/, next.config.ts). I added reset-password.mjs under
scripts/, but never told the runner stage to copy that folder over, so it
built fine but wasn't actually IN the container you ran `docker exec`
against. That's exactly the "Cannot find module '/app/scripts/reset-
password.mjs'" error.

Fixed: added one line to the Dockerfile so the runner stage copies
scripts/ too, the same way it already copies public/. I don't have a
Docker daemon available on my end to run a real build and prove it end to
end, but the fix is a direct, mechanical copy of the exact line already
working for public/ just above it -- I'm confident in it, and your next
deploy is the real test.
