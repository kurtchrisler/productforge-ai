ProductGenie AI — Manual password reset tool
==================================================

Short answer to "how do I or they reset it": right now, nobody can reset
their own password -- there's no "forgot password" link or email-sending
service wired into the app yet. This is a one-off admin tool so YOU can
reset a customer's password for them when they ask, until (if) a real
self-service flow gets built. See the note at the bottom about that.

What this does
---------------
Adds scripts/reset-password.mjs. You run it on the server, give it a
customer's email and a new password, and it:
  - Updates their password_hash in the database
  - Signs them out of any devices they were already logged into (a
    reasonable safety step any time a password changes)

Then you tell the customer the new password however you'd like (reply to
their support email, etc.) -- there's no "change your password" field in
Settings yet either, so that password stands until you reset it again or
that feature gets built.

I tested this end-to-end (signup, reset, confirm the old password is
rejected, confirm the new one works, confirm the old session got logged
out) before packaging it.

4. Whenever someone needs a password reset
-----------------------------------------------
Run this on the server (it runs INSIDE the app's Docker container, since
that's where the database and the bcrypt library live):

    docker exec -it productforge-ai node scripts/reset-password.mjs customer@example.com "NewPassword123"

Wrap the password in quotes. It'll print confirmation once it's done, or
tell you plainly if that email isn't found.

About a real "forgot password" flow
----------------------------------------
If you'd rather customers reset their own password (an actual "Forgot
password?" link on the login page that emails them a reset link), that's
a bigger feature -- it needs a transactional email service wired up
(something like Resend, SendGrid, or SMTP), since the app doesn't send any
email today. Let me know if you want that built and which email service
you'd like to use (or if you already have one set up for your other WP
Marketer Tools products that makes sense to reuse), and I'll build it.
