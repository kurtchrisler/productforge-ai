ProductGenie AI — Training Page + Real Upgrade Links
=====================================================

What this does
---------------
1. New "Training" link in the dashboard nav, going to a new Training page
   that plays the walkthrough video you sent over (product-genie-training.mp4).
2. Every place in the dashboard that talks about upgrading now links to a
   real purchase page instead of just sending people to Settings:
     - KDP Accelerator prompts -> https://www.wpmarketertools.com/product-genie-ai-kdp-accelerator/
     - Pro prompts             -> https://www.wpmarketertools.com/product-genie-ai-pro/
   (Settings links that are about activating an existing license or adding
   an OpenAI key were left alone — those aren't upgrade prompts.)

This update has TWO parts: the code (goes through your normal git flow)
and the video file itself (does NOT go through git — see why below, and
step 3 for how to get it onto the server).

Why the video doesn't go through git
--------------------------------------
Your .gitignore already excludes the whole /data/ folder ("app data (sqlite
db + generated pdfs)") so the repo doesn't fill up with generated PDFs,
covers, and EPUBs. The training video follows that same pattern — it's a
big, mostly-static file, so it lives on the server at
data/training/product-genie-training.mp4, served by a new API route the
same way PDFs/covers already are, and it's uploaded to the server directly
instead of riding along in git. That keeps your repo from growing by 40+MB
every time the video ever gets replaced.

1. Unzip the code update into your local clone
-------------------------------------------------
    Expand-Archive -Path training-page-and-upgrade-links-update.zip -DestinationPath C:\Users\kchri\Downloads\productforge-ai\aiproductfactory -Force

2. Commit and push
---------------------
    cd C:\Users\kchri\Downloads\productforge-ai\aiproductfactory
    git add -A
    git commit -m "Add Training page with walkthrough video, real upgrade purchase links"
    git push

3. Upload the video file to the server (one-time)
-----------------------------------------------------
The video was sent to you separately as product-genie-training.mp4 —
save it to your Downloads folder (or adjust the path below to wherever you
saved it), then from PowerShell:

    ssh cloudb23@144.208.68.97 "mkdir -p ~/productforge-ai/data/training"
    scp C:\Users\kchri\Downloads\product-genie-training.mp4 cloudb23@144.208.68.97:~/productforge-ai/data/training/product-genie-training.mp4

That data/training folder is mounted straight into the app container
(docker-compose.yml already maps ./data to /app/data), so nothing else
needs to change for the app to find it.

4. Deploy the code on the server
-------------------------------------
    ssh cloudb23@144.208.68.97
    cd ~/productforge-ai
    git pull && ./deploy.sh

Order doesn't matter between steps 3 and 4 — do them in either order, just
make sure both happen. If the video isn't at that path yet, the Training
page will just show a "Training video not found" message until it is.

5. Check it
---------------
Log into productgenie.app, you should see a "Training" link in the top nav
next to Settings, and it should play the video. Then check a Standard
account's dashboard and a product page to confirm the KDP Accelerator /
Pro upsell links now go to the real purchase pages (they'll open in a new
tab) instead of Settings.
